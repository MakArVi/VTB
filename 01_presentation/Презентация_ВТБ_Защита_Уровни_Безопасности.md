## Слайд 1. Концепция: от «карательного антифрода» к продукту «ВТБ Защита»

> ### ACTION TITLE: Трансформируем антифрод из центра затрат в продуктовую экосистему с 4 уровнями безопасности, которая снижает издержки банка и генерирует новую комиссионную выручку.

```
┌────────────────────────────────────────────────────────────────────────┐
│ Tier 4 | ВТБ ЗАЩИТА ПЛЮС (Premium / 149 ₽/мес или пакет «Привилегия»)  │
│ Киберстраховка до 1 млн ₽ + Кибер-консьерж 24/7 (SOS) + Darknet Monitor │
├────────────────────────────────────────────────────────────────────────┤
│ Tier 3 | ЗАЩИТА БЛИЗКИХ PRO (Семейный / Бесплатно)                     │
│ Запрет онлайн-кредитов без согласия + Аппрув переводов доверенным лицом│
├────────────────────────────────────────────────────────────────────────┤
│ Tier 2 | ВТБ СЕЙФ / MONEY LOCK (Сберегательный / Бесплатно)            │
│ Изоляция вкладов от СБП + 24-часовой Time-Lock на вывод накоплений     │
├────────────────────────────────────────────────────────────────────────┤
│ Tier 1 | СМАРТ-ЩИТ (Базовый / Бесплатно для всех 30,3 млн клиентов)   │
│ 161-ФЗ в фоне + 15-секундный Liveness-чекаут (селфи) вместо блокировок │
└────────────────────────────────────────────────────────────────────────┘
```

* **Главная идея:** Безопасность перестает быть невидимым контролером, раздражающим клиентов ложными блокировками. Мы даем клиенту понятный выбор уровней защиты под его стиль жизни.
* **Результат для клиента:** 90% легитимных клиентов получают бесшовный опыт, а уязвимые сегменты — непробиваемую защиту сбережений.
* **Результат для банка:** Сокращение очередей в офисах, рост NPS и новый поток комиссионных доходов.

## Слайд 3. Клиентский путь: как решается кейс Никиты (CJM «До» vs «После»)

> ### ACTION TITLE: Меры 161-ФЗ сохраняются полностью — меняется путь клиента вокруг них: подтверждение в приложении за минуту вместо звонка в контакт-центр, а при признаках обмана — пауза и звонок от банка.

| Этап | Как сейчас | Как будет («ВТБ Защита») |
| :--- | :--- | :--- |
| **1. Риск** | Накануне Никита сменил номер в ДБО, сегодня переводит непривычно крупную сумму новому получателю. | Те же признаки риска по 161-ФЗ: смена номера + нетипичная операция. |
| **2. Реакция банка** | Перевод приостановлен; клиент видит отказ без объяснения, продавец ждёт. | Перевод **так же приостановлен** (обязательная мера). Оркестратор дополнительно проверяет сигналы в моменте: идёт ли звонок, есть ли программы удалённого доступа, какой у получателя статус в базе ЦБ. Сменился номер через проверенный канал (офис, биометрия) — признак весит меньше. |
| **3. Коммуникация** | Клиент сам ищет причину и звонит в контакт-центр. | Push с причиной простыми словами: *«Вы недавно сменили номер и переводите новому получателю. Подтвердите, что это вы»*. |
| **4. Подтверждение** | Звонок в КЦ, ожидание на линии, устная проверка оператором. | Подтверждение **в приложении**: биометрия через ЕБС + 2 вопроса кнопками («Кто получатель?», «Вас просят перевести по телефону?»). |
| **5. Итог** | Покупка проходит с задержкой, продавец уже засомневался. | **Нет признаков обмана** → перевод исполняется после подтверждения, в рамках 161-ФЗ. **Есть признаки** (звонок, удалённый доступ, тревожный ответ) → быстрый путь закрыт: остаётся полная приостановка и звонок клиенту от банка. |
| **6. Затраты банка** | ~65 ₽ за обращение в КЦ (допущение финмодели). | ~2 ₽ за вызов биометрии (допущение); КЦ подключается только в рискованных случаях. |

> **Граница решения.** Если получатель есть в базе ЦБ, быстрого пути нет — по 161-ФЗ банк отказывает в переводе. Удобство мы меняем только на этапе подтверждения, сами ограничения не снимаем. **Метрики слайда:** доля подтверждений без звонка в КЦ, время до исполнения перевода, доля мошеннических операций, прошедших подтверждение (FN).

## Слайд 4. Защита от социальной инженерии: механика «ВТБ Сейф» (Money Lock)

> ### ACTION TITLE: Архитектурное разделение средств на текущий «Кошелек» и «Холодный сейф» предотвращает хищение крупных сумм даже при полном психологическом контроле жертвы.

```
       [ДОХОДЫ КЛИЕНТА]
              │
              ▼
    ┌───────────────────┐
    │  «ВТБ ОНЛАЙН»     │
    └─────────┬─────────┘
              │
      ┌───────┴────────────────────────┐
      ▼                                ▼
┌─────────────────────────┐   ┌─────────────────────────────────────────┐
│     ТЕКУЩИЙ КОШЕЛЕК     │   │             «ВТБ СЕЙФ»                  │
│       (Hot Wallet)      │   │            (Cold Vault)                 │
├─────────────────────────┤   ├─────────────────────────────────────────┤
│ • Баланс: 20–50 тыс. ₽  │   │ • Баланс: Вклады, накопительные счета   │
│ • Мгновенные покупки    │   │ • ИЗОЛИРОВАН от моментальных переводов  │
│ • СБП и переводы по P2P │   │ • Нельзя отправить через СБП за 1 клик  │
└─────────────────────────┘   └────────────────────┬────────────────────┘
                                                   │
                               Запрос на вывод     │
                               средств в кошелек   ▼
                              ┌─────────────────────────────────────────┐
                              │           24-ЧАСОВОЙ TIME-LOCK          │
                              │       (Период осознания / охлаждения)   │
                              │                      ИЛИ                │
                              │       ЛИЧНЫЙ ВИЗИТ В ОФИС С КАРТОЙ      │
                              └─────────────────────────────────────────┘
```

* **В чем уязвимость сейчас:** Мошенник («майор спецслужб») заставляет жертву закрыть вклад и отправить 1,5 млн ₽ через СБП на «безопасный счет» за 10 минут.
* **Как спасает «ВТБ Сейф»:** Деньги из Сейфа невозможно отправить моментально. На вывод наложен обязательный **24-часовой таймер охлаждения**.
* **Результат:** За 24 часа мошеннический транс спадает, жертва связывается с родственниками, все сбережения остаются в банке. По опыту Сингапура (DBS digiVault) — **0% хищений из Сейфа**.

## Слайд 5. Архитектура решения по модели IPO (Input &rarr; Process &rarr; Output)

> ### ACTION TITLE: Решение встраивается в инфраструктуру банка в виде 3 легковесных модулей, укладываясь в лимит бюджета 50 млн ₽ и срок 6 месяцев.

| Архитектурный блок | Назначение (Purpose) | Входные данные (Inputs) | Результат на выходе (Outputs) |
| :--- | :--- | :--- | :--- |
| **1. In-house Behavioral & Liveness SDK** | Мгновенная верификация воли клиента в приложении без визита в офис. | Данные фронтальной камеры смартфона (Liveness 3D), динамика касаний экрана, статус входящего вызова (Call State). | Флаг подтверждения личности `Liveness_Verified: True/False`, детекция работы под диктовку `Coercion_Score` (0–100). |
| **2. Dynamic Friction Orchestrator** | Маршрутизация проверки: выбор наименее болезненного сценария для клиента. | Агрегированный риск-скор операции, флаги 12 признаков 161-ФЗ, статус подключенного уровня защиты (Tier 1–4). | Выбор действия: 1) Проводка без задержки; 2) Запрос Liveness-селфи; 3) Запрос согласия Защитника; 4) 48ч заморозка по 161-ФЗ. |
| **3. Модуль Core-Banking «ВТБ Сейф»** | Логическая и регламентная изоляция накопительных счетов от каналов быстрых платежей. | Запрос клиента на перевод средств из Сейфа на текущий счет, таймер отсчета 24 часа. | Блокировка мгновенного списания, запуск таймера охлаждения, отправка пуш-уведомления родственникам («Защите близких»). |

## Слайд 6. Бизнес-кейс и финансовая модель проекта

> ### ACTION TITLE: Внедрение окупается за 4,1 месяца: банк получает совокупный чистый эффект +396,3 млн ₽/год (+148,1 млн ₽ Cost-out и +248,2 млн ₽ чистой комиссии Tier 4) при 3-летнем NPV +630,8 млн ₽.

```
                  ИНВЕСТИЦИИ (CAPEX)                                 ГОДОВОЙ ЭФФЕКТ (RUN-RATE)
          ┌──────────────────────────────────┐              ┌──────────────────────────────────────────┐
          │  50,0 млн ₽                      │              │  +148,1 млн ₽/год — Чистый Cost-out      │
          │  Срок внедрения: ровно 6 месяцев │ ───────────> │  +248,2 млн ₽/год — Чистый доход Tier 4  │
          │  (SDK, Core Сейф, Оркестратор)   │              │  +396,3 млн ₽/год — Совокупный Net Value │
          └──────────────────────────────────┘              └──────────────────────────────────────────┘
```

### 1. Детализация бюджета внедрения (CAPEX ≤ 50,0 млн ₽, 6 месяцев):
* **Разработка In-house Liveness SDK («ВТБ Онлайн»):** 14,0 млн ₽ (3 мес.)
* **Доработка ядра Core Banking под «ВТБ Сейф» (Air-Gap & Time-Lock):** 9,0 млн ₽ (2,5 мес.)
* **Оркестратор динамического трения (Smart Step-Up Engine):** 12,0 млн ₽ (3,5 мес.)
* **Семейный контур «Защита близких Pro» (Second-Party Consent & 31-ФЗ):** 8,0 млн ₽ (2 мес.)
* **Инфраструктура, аудит ИБ по 683-П и резерв:** 7,0 млн ₽
* **Итого CAPEX:** **50,0 млн ₽** | **Ежегодный OPEX платформы:** **18,0 млн ₽/год**

### 2. Структура годового экономического эффекта (Value Drivers):
* **Сокращение False Positives:** Снижение очных блокировок на 70% (-112 тыс. визитов в офисы по 750 ₽ = +84,0 млн ₽) и звонков в КЦ на 79% (-570 тыс. звонков по 65 ₽ = +37,1 млн ₽) → **+121,1 млн ₽/год**.
* **Предотвращение выплат по 161-ФЗ («правило 30 дней»):** Сокращение транзита на дроп-счета → **+45,0 млн ₽/год**.
* **Чистый Cost-out банка:** (+121,1M + 45,0M) - 18,0M OPEX = **+148,1 млн ₽/год**.
* **Монетизация Tier 4 («ВТБ Защита Плюс»):** 500 тыс. подписок по 149 ₽/мес = 894 млн ₽ выручки. Комиссия банка 30% (+268,2 млн ₽) минус затраты на 16 операторов линии SOS (-20,0 млн ₽) → **+248,2 млн ₽/год чистой прибыли**.

### 3. Инвестиционные метрики и стресс-тестирование:
* **Срок окупаемости:** **4,1 месяца** (только за счет сокращения затрат!) и **1,5 месяца** (совокупный).
* **3-летний NPV (ставка 15%):** **+630,8 млн ₽** | **IRR:** **339,5% годовых**.
* **Точка безубыточности (Break-even):** Проект окупается за 1 год даже без единой платной подписки при снижении ложных блокировок всего на **13,8%** (у нас достигается 65–70%).
* **5 обязательных KPI кейса:** Потери от фрода **-30,0% (-1 635 млн ₽)**; True Positives **+28,0% (до 98,5%)**; False Positives **-65..70%**; Рост NPS розницы **+5,5 п.п.**; Число атак **-18%** (успешность социнженерии **-45%**).
