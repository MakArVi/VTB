## 🎯 Суть решения: Продуктовая линейка «ВТБ Защита: 4 уровня»

Мы трансформируем антифрод из «карательного инструмента» в **продуктовую экосистему с 4 уровнями безопасности**:

```
┌────────────────────────────────────────────────────────────────────────┐
│ Tier 4 | ВТБ ЗАЩИТА ПЛЮС (Premium / 149 ₽/мес или пакет «Привилегия»)  │
│ Киберстраховка до 1 млн ₽ + Кибер-консьерж 24/7 (SOS) + Мониторинг darknet
├────────────────────────────────────────────────────────────────────────┤
│ Tier 3 | ЗАЩИТА БЛИЗКИХ PRO (Семейный / Бесплатно)                     │
│ Кредитный замок (Second-Party Consent) + пре-алерты при звонках мошенников │
├────────────────────────────────────────────────────────────────────────┤
│ Tier 2 | ВТБ СЕЙФ / MONEY LOCK (Сберегательный / Бесплатно)            │
│ Изоляция вкладов от СБП (Air-Gap) + 24ч Time-Lock на вывод накоплений  │
├────────────────────────────────────────────────────────────────────────┤
│ Tier 1 | СМАРТ-ЩИТ (Базовый / Бесплатно для всех 30,3 млн клиентов)   │
│ 15-секундный Liveness Step-Up (видеоселфи) вместо 48ч блокировок       │
└────────────────────────────────────────────────────────────────────────┘
```

### Ключевые победные метрики:
* **CAPEX:** **50,0 млн ₽** (строго в лимите кейса).
* **Срок внедрения:** **Ровно 6 месяцев** до промышленного пилота.
* **Экономия OPEX банка:** **+121,5 млн ₽/год** (минус 112 тыс. визитов в офисы и 570 тыс. звонков в колл-центр).
* **Новая прибыль (Tier 4):** **+268,2 млн ₽/год** чистой прибыли при 500 тыс. подписчиков.
* **Срок окупаемости:** **4,1 месяца**.
* **Рост NPS:** **+5,5 п.п.**
